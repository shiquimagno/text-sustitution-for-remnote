# Project instructions

- The user operates their RemNote account. Do not control RemNote, its browser session, or modify account data through connectors. Give the user one concrete manual test at a time and wait for the result when it is needed.
- Work autonomously on local source files, compilation and automated tests. Do not equate these checks with verification in the real RemNote editor.
- Keep OpenSpec tasks pending when their stated acceptance checks require manual evidence that has not been provided.
- Keep the initial compatibility prototype disabled until the user explicitly activates its test command. Scope the prototype to the selected test Rem.
